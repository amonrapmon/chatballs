# Отображение сохранённых ответов

Виджет, рабочая лента, TestChatFeed и предпросмотр редактора используют
`PreparedMessage` из `packages/ui`. Потребители передают сохранённый контракт,
не запрашивают исходники для сборки и не вставляют `contentHtml` в DOM.

Видимый iframe имеет пустой sandbox и no-referrer. Существующий скрытый
измерительный iframe не разрешает скрипты; его документ нужен только для
чтения размеров. В оба документа перед сохранённой разметкой добавляется CSP,
запрещающая загрузку ресурсов, формы и base URI. Версия/изоляция/документ
проверяются до создания iframe. Повреждённый или неподдерживаемый снимок
показывает экранированный сохранённый текст без внутренних ссылок подготовки
и псевдонимов. Выбранная текстовая доставка всегда использует `text`.

Изменение высоты карточки учитывает прокрутку ближайшей ленты. Карточка над
областью чтения компенсирует прирост высоты; лента у нижней границы следует за
новой высотой. Существующие окна истории, ключи сообщений и WebSocket
инвалидация не заменяются.

Рабочая лента берёт название из `template.name` отправленного снимка.
Кнопка раскрывает сохранённый `text` в том же пузыре. Автор, время и отметка
прочтения остаются в `MessageBubble`; метаданные и пояснение находятся снаружи
содержимого карточки, по F1/F3. Для текстовой доставки действий карточки нет.
Входящая почта продолжает использовать `EmailMessageBody`, файлы и голосовые
имеют приоритет перед представлением.

Только защищённое окно истории сотрудника может дополнительно вернуть
`templateUpdatedAt`. Один запрос на окно проверяет организацию, существование
исходного шаблона и строго более новую ревизию навыка. Новое название,
инструкция, схема и исходники не возвращаются. При неизвестной ревизии,
отсутствующем шаблоне или удалённом навыке пояснения нет; снимок не изменяется.
Публичная история этого поля не получает и библиотеку не читает.

TestChatFeed сохраняет прежнюю оболочку и использует снимок рядом с ответом
проверочного API. В историю следующего запроса по-прежнему отправляется текст.
Внутренние операции навыка новых плашек не создают.
