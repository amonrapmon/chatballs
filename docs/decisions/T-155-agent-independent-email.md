# Почтовое продолжение без привязки ящика к агенту

Статус: принято владельцем 15.10.2026 в задаче T-155.
Основание: «надо убрать привязку к агенту. зафиксируй как решение и исправь».

## Решение

Для почтового продолжения существующего WEB-обращения EMAIL-подключение
не обязано быть привязано к агенту. Наличие и активность его агентского
канала не определяют доступность отправки, повторов и связанных ответов.
Исходные агент, канал, контакт, WEB-подключение, группа и ответственный
веб-диалога сохраняются. Новый агент или канал для ящика автоматически
не создаются, подключения и секреты не перепривязываются.

Обязательны прежние проверки: организация, право ответа в исходном диалоге,
сохранённый адрес контакта, активное EMAIL-подключение, отсутствие ошибки
проверки, пароль и конфигурация IMAP/SMTP, исключение демо-подключений.
Отсутствие статуса OK само по себе не является ошибкой: статус не подменяется.
Почта установки для приглашений и восстановления доступа остаётся отдельной.

Опрос IMAP активного ящика не зависит от привязки к агенту и начинается
до первого почтового продолжения, сохраняя штатный курсор и backoff.
Это позволяет инициализировать курсор до отправки и принимать новые ответы.
Из ящика без активного обычного маршрута обрабатываются только достоверно
связанные ответы: In-Reply-To/References, тот же ящик, организация и отправитель.
Они используют маршрут исходного веб-обращения, включая связанного преемника
закрытого диалога. Несвязанные письма не назначаются случайному агенту и
не создают обращения без настроенного обычного маршрута.

Если у ящика есть активный обычный маршрут, приём новых самостоятельных
почтовых обращений работает по прежним правилам. Отключение самого подключения
останавливает его использование. Ошибка SMTP не объявляется успешной отправкой.

## Связь с документами

Решение уточняет R-1, R-2 и R-4 SPEC-0031 и ADR-0035. Требование ADR-0015
«каждый [ящик] привязан к одному агенту» больше не применяется к почтовому
продолжению веб-обращения. Для создания самостоятельного обращения по
несвязанному письму сохраняется необходимость обычного маршрута.

Этот документ фиксирует принятое решение в репозитории задачи. Каталог
.skaro принадлежит Skaro и вручную не редактировался; MCP не предоставляет
операции изменения ADR. Уточнение ADR-0015 для Skaro содержится здесь.
