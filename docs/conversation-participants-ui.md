# Участники, авторство и уведомление специалиста

Baseline: `design/baseline/platform-expansion/Чат · состояния.dc.html` (U1–U8, P6),
`Чат · совмещённые кадры.dc.html` (K1–K2), `Настройки · новые разделы.dc.html`
(N1–N2, лимит) и `Клиентская сторона.dc.html` (W1).

Ветка включает main `516bf528`, окончательный API T-098 и зависимости T-092/T-071.
Пустые объединяющие миграции сохраняют опубликованные ветви без новых операций схемы.

Состав расположен после ответственного, перед группой. Используются общие
`WorkStatusLabel`, `SmallAvatar` и оповещения доступности. Рабочий статус и
присутствие независимы; статус назначения не запрещает участие. Имена, состав,
лимит и ошибки читаются из API. Выбор и причина сохраняются при неудаче.

Участник отвечает без перехвата и смены ответственного. Доступные действия
задаются API: участие само по себе не открывает назначение, звонки или управление.
Подтверждённый 404 очищает карточку, редактор и строку списка; ответы запросов,
начатых до очистки, не возвращают отозванную строку. Экран U8 использует факт
собственного завершения участия и ранее прочитанное имя контакта, без причины.

Журнал объединяет передачи, подключения и завершения участия. Фильтры и
пагинация серверные; сохранённая причина передачи не заменяется новым названием.
Переименование и отключение причины отмечаются по фактическим данным.

Настройка лимита принимает 1–10. Ошибка сохраняет ввод и показывает ответ API.
Снижение лимита не удаляет участников. Дата и инициатор сохранения читаются из API.
Остальные карточки N1–N2 относятся к отдельному UI передачи и политики назначения.

В рабочей ленте и виджете ответ подписан именем отправившего сотрудника, в том
числе после завершения участия. Публичная история не подставляет служебный email.
Уведомление специалиста нейтральное и содержит согласованный публичный текст.
