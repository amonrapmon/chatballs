# Настройки и карточка анализа качества

Настройки доступны OWNER/ADMIN в `/organizations/{public_id}/settings/quality`.
Переключатель сохраняет только включение; редактор сохраняет новый набор
отдельной версией. Дата, номер текущей/следующей версии и выбор шкал приходят
из штатного API. Старые шкалы и числовые типы сохраняются при редактировании
названия или описания. Исходно функция выключена; пустой набор не включает её.

Карточка `/organizations/{public_id}/conversations/{id}/quality` открывается
из меню «⋯» завершённого диалога. Пункт видят OWNER/ADMIN и супервизор, когда
сервер подтвердил контроль группы. Оператору карточка недоступна. Настройки
и ручной запуск остаются только у OWNER/ADMIN. Все запросы проверяют текущую
область доступа на сервере; отзыв доступа при опросе скрывает прежние данные.

Карточка использует критерии выбранной ревизии, а не текущие настройки.
При повторном запуске сохраняется последний успешный результат; прежние
запуски можно выбрать отдельно. Исходная оценка AI, объяснение и рекомендации
не меняются при исправлении. Изменённая оценка показывает зачёркнутую исходную,
автора, серверное время, причину и полную историю исправлений.

Редактор требует причину и выбирает значение из шкалы исходной версии.
Исправление отправляет сохранённую `expectedRevision`. При HTTP 409 форма
и причина сохраняются, актуальная история загружается; повторная отправка
доступна только после «Показать актуальное». Автоматического перезаписывания
или повторной отправки нет.

Основания загружаются по серверным ссылкам с повторной проверкой доступа.
Ссылки открывают обычную переписку с `?conversation={id}#message-{id}`.
Штатная лента догружает предыдущие страницы и прокручивает к сообщению;
отдельное представление переписки и обход её прав не создаются.

## Baseline и решения владельца

Источники: `design/baseline/platform-expansion/Настройки · новые разделы.dc.html`
(N12–N13) и `Статистика и качество.dc.html` (QA1–QA6), подключённые владельцем
согласно `INTEGRATION.md`. Решения в чате T-142 от 14.10.2026:

- Разрешено расширение API названием критерия, датой версии и каталогом шкал.
  Ссылка «История версий» убрана до появления утверждённого состояния.
- Подписи временных ответов используют среднее от начала ожидания. Обещание
  десятиминутной задержки заменено запуском после закрытия при включённой
  настройке; обещание длительности до минуты заменено ожиданием завершения.
  Порядок и расположение блоков сохранены.
- Разрешён пункт «Анализ качества» с существующей sparkles в меню завершённого
  диалога перед диагностической выгрузкой.
- Для текущей проверки выбран штатный DEMO. Успешный браузерный результат
  и его корректировка остаются открытыми до доступного реального провайдера.

Новых экранов истории версий, фиктивных ответов API, seed, смены ролей,
паролей или учётных записей задача не добавляет. Снимки и фактические проверки
перечислены в `docs/verification/T-142/README.md`.
