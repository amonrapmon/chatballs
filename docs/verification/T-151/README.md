## Исполняемые проверки

Все команды выполнены на текущем коде в рабочей копии T-151:

```powershell
npm --workspace @chatballs/internal-ui run build
npm --workspace @chatballs/internal-ui run test -- src/features/handling-rules/model.test.ts src/features/handling-rules/JournalRows.test.tsx src/router.test.ts src/auth/access.test.ts src/i18n/catalog.test.ts
docker compose exec -T backend-admin pytest chatballs/conversations/rules/test_rule_api.py chatballs/conversations/rules/test_journal_timezone.py --reuse-db -q
docker compose exec -T backend-admin ruff check chatballs/conversations/rules/views.py chatballs/conversations/rules/test_journal_timezone.py
git diff --check
```

Сборка tsc/Vite успешна; 46 frontend-тестов и 11 backend-тестов прошли;
ruff и проверка diff успешны. Предупреждения: существующий большой Vite chunk,
устаревающие Django CheckConstraint и отсутствующий каталог staticfiles.
Полный набор тестов не запускался. Новые модули небольшой длины; страница
собирает компоненты, загрузка, фильтрация и представление разделены.

Backend-тесты проверяют timezone текущей организации, игнорирование подмены
timezone запросом, доступ супервизора только к подконтрольным группам,
запрет настроек для него, запрет журнала для сотрудника и супервизора без
групп, изоляцию другой организации и безопасные причины ошибок.
Frontend-тесты проверяют независимый PATCH, обязательные поля, пределы срока,
календарный день организации на границе UTC, комбинацию фильтров, поиск по
доступным именам, маршруты и права, отображение ошибки без технических кодов
и отмены без ложного времени выполнения, полноту i18n.
