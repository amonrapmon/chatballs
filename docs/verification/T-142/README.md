## Окружение

`skaro-chatballs-t-142`, запуск и пересборка через Skaro `start_environment`.
Frontend `http://localhost:20013`, backend-app `http://localhost:20011`,
web-chat `http://localhost:20014`. Same-origin прокси frontend использует
backend-app этого Compose-проекта. PostgreSQL и Redis healthy; штатный
readiness проверяет БД и Redis. `backend-admin` добавлен в команду окружения
через `configure_environment`, без новых host-портов. Два штатных worker-events
и worker работают. DemoDataset организации 1 уже имел статус INSTALLED.

Использованы существующие демо-учётные записи администратора Елены Кузнецовой
и оператора Светланы Петровой. Seed, смена паролей, TOTP, прав и ролей не
выполнялись. В другой организации был DEMO-агент с моделью demo, но его
настройки и данные не использовались для обхода прав текущей организации.
