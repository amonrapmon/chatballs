# T-132 — проверка клиентской оценки

Владелец в чате T-132 подтвердил baseline:

- `design/baseline/platform-expansion/Настройки · новые разделы.dc.html`, N10–N11;
- `design/baseline/platform-expansion/Клиентская сторона.dc.html`, W2, R1–R6;
- `design/baseline/platform-expansion/Чат · состояния.dc.html`, R1–R4.

Также разрешены необходимые дополнения штатного API и временная проверка
супервизорских прав существующей демо-сотрудницы в одноразовой БД задачи.

## Контур и команды

Окружение `skaro-chatballs-t-132`, созданное и пересобранное через Skaro:
frontend `http://localhost:20004`, backend-app `http://localhost:20002`,
web-chat `http://localhost:20005`. Frontend и web-chat используют same-origin
прокси на `backend-app` этого Compose-проекта. PostgreSQL и Redis healthy;
`backend-admin` включён в штатную команду окружения для тестов. Существующий
DemoDataset имел статус INSTALLED; seed и изменение паролей/TOTP не выполнялись.

Выполнено:

```powershell
docker compose exec -T frontend npm run build --workspace @chatballs/internal-ui
docker compose exec -T web-chat npm run build --workspace @chatballs/web-chat
docker compose exec -T backend-admin python manage.py check
docker compose exec -T backend-admin python manage.py makemigrations --check --dry-run
docker compose exec -T backend-admin ruff check chatballs/ratings
docker compose exec -T backend-admin pytest -q --reuse-db chatballs/ratings/test_ui_contract.py chatballs/ratings/test_public.py chatballs/ratings/test_results.py chatballs/ratings/test_delivery.py
```

Обе сборки прошли. Последнее исправление CSS-токена фона и цвета текста
проверено в браузере; отдельная повторная сборка для этой мелкой правки
не запускалась по правилу владельца. Django check: 0 issues; миграции: No changes detected;
ruff: All checks passed; адресные тесты: **21 passed**. Полный набор не запускался.
Новые компоненты и модули меньше 180 строк; layout, API, состояние, словари и
представления разделены. В прежних больших каталогах изменена только регистрация
новых отдельных словарей, в прежних экранах — точки подключения компонентов.

Реальные запросы и UI, без перехвата/подмены API. Администратор — существующая
Елена Кузнецова. В существующий опубликованный виджет подключения 22 добавлен
текущий разрешённый origin web-chat, без смены подключения, ключей или сервиса.

## Наблюдения вне изменений оценки

На закрытых WEB-диалогах прежний блок почтового продолжения регулярно запрашивает
`email/options/` и получает 409. При обновлении прежней ленты встречалось сообщение
React о повторяющемся ключе диалога; перезагрузка очищала отображение. Эти модули
в T-132 не менялись. Для проверки оценок использовались реальные завершённые
обращения и ответы собственных endpoint’ов, а не скрытие этих ошибок.
