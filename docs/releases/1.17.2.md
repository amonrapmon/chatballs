# Chatballs 1.17.2

## Исправления

- Встроенный веб-виджет делегирует доступ к микрофону своему iframe: браузер
  может запросить разрешение на запись голосового сообщения на сайте
  с другим адресом, чем установка Chatballs.
- Доступ ограничен адресом iframe. Согласие пользователя по-прежнему требуется;
  запрет микрофона политикой родительского сайта не обходится. Доступ к камере
  не добавлен.

## Серверные изменения из main

- Добавлены справочник причин и внутренний журнал передач диалога.
- Добавлены данные участия сотрудников в диалоге и лимит дополнительных
  участников организации. Прежние назначения сохраняются; автоматическое
  создание участников не выполняется.
- Эти изменения подготавливают серверную модель; новые экраны управления
  передачами и участниками в этот релиз не входят.

## Проверки

Целевые регрессионные тесты публичного загрузчика выполнены перед выпуском.
Сборка и публикация образов выполняются штатным GitHub Actions workflow.
HTTPS-сценарий записи на стороннем сайте агентом не подтверждён; ранее
в штатном окружении задачи проверены запись с реального микрофона,
отправка через backend, воспроизведение и обработка отказов.

## Обновление

Новые миграции: `conversations.0030_transfer_data`,
`conversations.0031_participant_data`,
`identity.0042_organization_participant_limit`,
`tenancy.0041_transfer_guards`, `tenancy.0042_participant_guards`.
Их применяет штатный сервис `init`. Перед обновлением следует сохранить
резервную копию данных и секретов. Используйте `compose.yaml` этого релиза
и существующие Compose override-файлы установки.
