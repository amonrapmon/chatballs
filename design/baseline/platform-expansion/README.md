# Handoff: Chatballs — 12 функций поверх baseline v2

## Что это
Дизайн 12 новых функций рабочего места Chatballs: черновик AI для сотрудника, передача диалога, участники, внутренние комментарии, рабочий статус, супервизор, статистика, шаблоны (личные/общие, категории, теги), письмо из веб-диалога и состояние посетителя, оценка клиента, AI-анализ качества, правила обработки. Плюс сквозные правки: иконки рабочего статуса, иконка агента, новый логотип, пункт «Помощь» в сайдбаре.

## О файлах
Файлы `*.dc.html` — **дизайн-референсы в HTML**, а не продакшн-код. Задача — воспроизвести их в `apps/internal-ui` (React + существующие `shared/`, `features/`, `layout/`) и `apps/web-chat` на принятых в репозитории паттернах. Визуальная основа взята из `design/baseline/Chatballs Baseline v2` и кода (`shared/icons.tsx`, `shared/links.css`, `features/conversations/templateVariables.ts`, `features/settings/sections.ts`) — новых токенов не вводилось.

Открыть: любой файл открывается в браузере напрямую (рядом должны лежать `support.js`, `chat-model.js`, `assets/`). Холст можно двигать и масштабировать. В панели Tweaks: `theme` (light/dark), `accent`, `frame`/`section` — показать один кадр (например `k3`, `n14`, `s-ai`).

## Точность
**Hi-fi.** Цвета, размеры, отступы, тексты — финальные. Все строки интерфейса на русском — использовать как есть (через i18n).

## Ключевые решения (согласовать/учесть)
- **Навигация:** «Статистика» и «Настройки» отделены линией; после «Настроек» — «Помощь» → `https://chatballs.com.edevs.tech/` (новая вкладка). У сотрудника-супервизора в сайдбаре чата: линия, «Статистика», «Помощь».
- **Настройки:** новые разделы «Передача и участники», «Оценки клиентов», «Анализ качества». «Когда звать на помощь» → «Правила обработки» (сроки ожидания и возврат назначенного становятся правилами 2 и 4 — *требует согласования*).
- **Супервизор** — полномочие поверх роли (не роль), с отдельным списком групп под контролем. Пустой список ≠ вся организация.
- **Присутствие vs рабочий статус:** круглая точка на аватаре = приложение открыто; иконка lucide = рабочий статус, выбирается сотрудником.
- **Правило недоступности:** нет отношения к действию — скрыть; право есть, условие не выполнено — показать приглушённым с причиной (tooltip + строка под элементом).
- **Оценка:** шкала 1–5, отображается звёздами; форма по ссылке, без переписки и имён. Разные шкалы и версии критериев не усредняются вместе.
- **Отсутствующее значение** в статистике — «—» с подсказкой, не 0; незавершённый интервал заштрихован.

## Токены (из baseline v2, `chat-model.js → theme()`)
Светлая: canvas `#e4e6ea`, surface `#ffffff`, surface2 `#fafafa`, feed `#f5f6f8`, n1 `#1f1f1f` … n10 `#fafafa` (n2 `#262626`, n3 `#595959`, n4 `#8c8c8c`, n5 `#bfbfbf`, n6 `#d9d9d9`, n7 `#e8e8e8`, n8 `#f0f0f0`, n9 `#f5f5f5`), accent `#1677ff`, ai `#722ed1`, warn `#faad14`/text `#d48806`, ok `#52c41a`/text `#237a3f`, err `#f5222d`/text `#cf1322`. Тинты: `color-mix(in srgb, <цвет> 10–12%, surface)`. Тёмная тема — значения в `theme()`.
Шрифт: системный стек `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, …`; моно `'SF Mono', ui-monospace, Menlo`.
Размеры: текст 11–15px (заголовки 16/20/22px, 700); кнопки 30/34/36px, радиус 7–8px; поля 34–36px, радиус 8px; карточки радиус 12px, бордер `n8`; модалки радиус 12px, тень `0 16px 48px rgba(0,0,0,.22)`; поповеры радиус 10px, тень `0 6px 20px rgba(0,0,0,.12)`. Мобильные касания ≥ 44px.

## Иконки
Контурные 24×24, stroke 1.8–2.2, round caps (как `shared/icons.tsx`).
- Рабочий статус (lucide): Готов — `circle-check` `#52c41a`; Занят — `circle-minus` `#ff4d4f`; Перерыв — `coffee` `#faad14`; Недоступен — `moon` `#8c8c8c`.
- Агент: контурная версия бота из веб-виджета (без анимации моргания) — путь `I.robot` в `chat-model.js`.
- Помощь: `circle-help` + малая стрелка внешней ссылки.
- Звёзды оценки: заливка `#faad14`, пустые — контур `#d9d9d9`.

## Состояния и данные
Каждый кадр в файлах — отдельное состояние; подписи над кадрами описывают триггер и поведение. Структуры данных (сообщения, участники, передачи, попытки отправки письма, запуски анализа, журнал правил) видны в `build()` каждого файла и в `chat-model.js`.
